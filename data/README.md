# Data folder

Put these two files here so the website can load them automatically:

- `ae.train`
- `ae.test`

Get them from the UCI "Japanese Vowels" dataset (https://doi.org/10.24432/C5NS47), unzip the download, and copy those two files into this folder.
Check the dataset page for its licence and credit the dataset donors (Kudo, Toyama and Shimbo) when you share it.

If you don't add the files, the site still works: press **Load data** in the terminal and choose them from your computer. Nothing is uploaded anywhere.
