How it works

Four boxes, one equation

Sound inA recording stored as 12 numbers per moment in time.
Never trainedReservoirA tangled web of neurons. In Brainoware: a living organoid. Here: simulated.
TrainedReadoutA ridge classifier that learns which pattern means which speaker.
Speaker guessOne of 9 speakers.
x = (1 - leak) * x + leak * tanh(W_in @ u + W @ x)

x is every neuron’s activity, u is the sound at that moment, W_in is how sound pushes on neurons, and W is how neurons push on each other. Both matrices are random and never change.

1. Load and scale the data

UCI Japanese Vowels: 9 speakers say the same sound. 270 recordings train the readout; 370 test it. Every channel is rescaled to between -1 and 1 using only training data, so the test set cannot leak in.

2. Build a random reservoir

10% of neurons connect to each other. The connection matrix is rescaled so its spectral radius is 0.9, which keeps activity from exploding. A seed decides which random reservoir you get. If a tiny reservoir comes out with no connections, it is redrawn.

3. Summarise each recording

Recordings have different lengths, so each is summarised as the average reservoir state plus the final state.

4. Train only the readout

A ridge classifier learns from the 270 training summaries. It picks its own regularisation strength by leave-one-out error on training data only. This is the only trained part.

5. Compare with a baseline

The same readout on the raw sound numbers, with no reservoir. If the reservoir does not beat it, it is not adding anything.

What this does not show

No living neurons and no electrode array: the reservoir is simulated and fixed. A different dataset from the paper’s 240 clips from eight speakers, so these accuracies cannot be compared with Brainoware’s ~78%. One dataset, one task, one test split. What I rebuilt is the method, not the result.
